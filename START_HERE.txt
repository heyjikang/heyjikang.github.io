JIKANG 个人数字展馆 · 快速入口
========================================

完整操作请阅读 README.md。

发布步骤：
1. GitHub 新建公开仓库，比如 jikang-site。
2. 将本目录下全部文件推送到 main 分支，包括 .github/。
3. Settings → Pages → Source 选择 GitHub Actions。
4. 打开 Actions 检查 Publish JIKANG Studio 发布成功。
5. 在 config.yml 更新信息；在 content/notes/ 写 Markdown 文章。

项目已经内置 GitHub Pages 自动部署、独立文章页面和 SEO 配置。
已构建网页在 dist/ 内，电脑可直接本地预览。

本地预览：
python -m pip install -r requirements.txt
python build.py
python -m http.server 8000 --directory dist

浏览器打开 http://localhost:8000
